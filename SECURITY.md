# Security policy

Homedrive is meant to be exposed on the internet, so security reports are very welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: *Security → Report a vulnerability* on this repository.

Include what you found, how to reproduce it, and which version you tested. You'll get a reply within a week. Fixes for confirmed issues are released as soon as possible and credited in the changelog unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
